# Information Security

## Passwords and accounts

Every employee uses the company password manager and must not reuse passwords. Two-factor authentication is mandatory for email, the code repository and the cloud console. Hardware security keys are issued to administrators.

## Reporting incidents

A lost laptop, a phishing email that was clicked, or any suspected data leak must be reported to security@example.com within 1 hour of discovery. Do not try to investigate or delete anything yourself. The security team opens a ticket with the prefix SEC- and coordinates the response.

## Personal data and GDPR

Personal data of customers may only be processed for the purpose it was collected for. Access to production data requires a ticket approved by the data owner and expires after 7 days. Data subject requests, such as access or erasure, must be forwarded to the Data Protection Officer immediately; the legal deadline to answer is one month.

## Clean desk

Screens are locked whenever the employee leaves the workstation, and printed confidential documents are shredded, not thrown in the bin. Visitors are escorted and must wear a visitor badge.

## Software and AI tools

Only software from the approved catalogue may be installed. Customer data, source code and credentials must never be pasted into public AI chat tools. Approved AI assistants are configured by the platform team with data retention disabled.
